# إكستنشن كروم — Khiam Ops (متابعة الموظف)

إضافة MV3 **بدون خطوة بناء** — تتحمّل مباشرة في كروم.

## التحميل (Load unpacked)
1. تأكد إن الـ backend المحلي شغّال: `pnpm backend` (http://localhost:8787).
2. افتح كروم على `chrome://extensions`.
3. فعّل **وضع المطوّر** (Developer mode) من أعلى اليمين.
4. اضغط **Load unpacked** واختر فولدر: `apps/extension`.
5. اضغط أيقونة الإضافة → سجّل الدخول بالكود (مثلاً `K1002`) ورقم الواتساب → وافق على إشعار المتابعة.

## أين يظهر الشريط؟
يُحقن شريط علوي ثابت (ارتفاع 36px) داخل:
- `business.facebook.com` (Meta Business Suite)
- `web.whatsapp.com`
- `www.instagram.com`
- `*.operix.co`
- `localhost:8787` (صفحة تجربة: افتح http://localhost:8787/test لمعاينة الشريط بدون ميتا)

## المزايا (الوحدة 1)
- الشريط الثابت: الحالة + اسم الموظف + ترتيبك اليوم + أزرار الشيفت + الشات.
- أزرار: **ابدأ الشيفت / استراحة (صلاة·حمام·بريك) / إنهاء الشيفت** (مع ملاحظات تسليم الوردية).
- **نغمة Enter**: كل ما تبعت رسالة/تعليق بزرار Enter يرنّ ويتسجّل عدّاد.
- **heartbeat**: يبعت حالتك (online/typing/سرعة الكتابة/النافذة) للداشبورد كل 10 ثواني.
- **إشعارات الإدارة**: تظهر كـ toast + صوت (ومخالفات).
- **Spotlight**: لمّا الإدارة تفعّل عين الرقابة يظهر 🔴 + صوت تنبيه.
- **الشات الداخلي** للفريق.

## ملاحظات
- كل الاتصال بالـ backend يمرّ عبر `background.js` (عشان CSP بتاعة ميتا متمنعش fetch).
- العنوان المحلي `http://localhost:8787` مكتوب في `background.js` و`manifest.json` — يتغيّر لعنوان Cloudflare Worker وقت النشر.
- لاحقاً ممكن ننقله لـ WXT لو احتجنا HMR وتحديث تلقائي؛ دلوقتي النسخة دي أبسط وأضمن للتحميل.
